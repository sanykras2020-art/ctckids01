# Игорь Компаниец — final landing v3

Static single-page site prepared for Vercel preview and SourceCraft Sites.

## SourceCraft

This directory is intentionally self-contained for `git subtree split` publication. After splitting `igor-site-v3`, `.sourcecraft/sites.yaml` becomes a repository-root config.

Expected public URL format:

`https://<sourcecraft-organization>.sourcecraft.site/igor-kompaniets`

SourceCraft requires a public repository in a public organization.

## Files

- `index.html` — final static landing;
- `.sourcecraft/sites.yaml` — Sites config;
- `assets/` — portrait and old-site archive when synchronized;
- image fallbacks in HTML point to the current public portrait / previous Tilda CDN so the page remains usable if local asset sync is not yet present.

## Content policy

Current-project wording preserves claims from Igor's previous public site. Historical case wording uses the researched evidence layer and deliberately avoids unresolved superlatives / role inflation.
