# СТС Kids — Figma-ready дизайн-система

Эта библиотека собрана как production-инструмент для команд:
- дизайн
- SMM
- эфир/promotions

Внутри:
- структура Figma-файла (`docs/structure.md`)
- naming-система (`docs/naming.md`)
- component system (`docs/components.md`)
- сценарии применения и антиошибки (`docs/usage.md`)
- implementation plan ручной сборки (`docs/implementation-plan.md`)
- design tokens в JSON (`tokens/*.json`)

## Быстрый старт
1. Создай файл `STS Kids / Design System`.
2. Создай Pages по `docs/structure.md`.
3. Подними стили и переменные из `tokens/`.
4. Собери базовые компоненты по `docs/components.md`.
5. Проверь naming в `docs/naming.md`.
6. Протестируй на реальных задачах по `docs/usage.md`.
7. Проведи сборку по чеклисту `docs/implementation-plan.md`.

## Принципы
- Просто для ежедневной работы.
- Масштабируется без переименований и хаоса.
- Ориентация на TV branding: ярко, динамично, органично.
